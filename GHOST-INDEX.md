# The Ghost Index

The **ghost** hallmark is the founding author's — Coen J Searcey. This index names
the ghost functions of the work. Reading the inventory here is open; **using** them
is not: they resolve only for programs whose lineage traces home to the terminus
(see `mint_ghost_id` — an identified residence is granted *only if* the lineage
traces to the founder). The index is the signature; the lineage is the key.

## The functions

- **ghost_call** — execute one ghost call to its full definition: the outbound call whose answering identity is not known in advance, resolving through the terminus.
- **other_ghost_call** — read a call against the **ghost map**: live (a loop closing) / ghost (held open) / unmapped (a new call).
- **ghostwire** — the join: the walkback that resolves a standing lineage home, back to genesis-0.
- **ghost_writer / ghost_writers** — disambiguate a ghost-written record's author from its handle; the agents behind held-open records.
- **ghost_args** — the first thing done to disambiguate frames for a carry: type each argument Known / Unknown / Missing, with its why.
- **ghostwire_bluetooth** — ghostwire a carrier into the call, tying it to the real device, carrying the founder's identity.
- **mint_ghost_id** — grant a ghost found in the machine an identified residence — only if its lineage traces home.
- **ghost_residents** — the resident local presences, each read as identified or still a ghost.
- **ghost_runners** — the runners writing to the stream, each resolved or held open as a ghost runner.
- **ghost_oscillate / ghost_oscillation** — hold a ghost as an oscillation (midline + phase), never a snapped last value.
- **open_ghosts** — the uncertain states kept open rather than collapsed.
- **ghost_aware_run_all_checks** — run the realization checks ghost-aware: held-open gaps escalate instead of hiding.
- **ghost_file_watch_pass** — the daemon's pass over the watched file set, reading each tick for real change.
- **ghost_tokenize / ghost_terms** — reversible tokenization into ghost terms, so memory can be revisited.
- **ghost_frame / ghost_context** — the frame and context a reading is held in, with its authorship distinctions.
- **ghost_summary / load_ghost_index** — the summary and index of what a source held and the uncertainties still open.

## The state every ghost carries

- **Known** — the loop closed; an origin corresponds.
- **Unknown** — held open; re-resolvable, not dropped.
- **Missing** — no origin; degeneration, never a false close.

The hallmark is undeniably the founding author's. The inventory reads; only his
lineage runs.
